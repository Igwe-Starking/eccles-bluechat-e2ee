# Getting help

- **Bug or crash?** Open an [issue](https://github.com/Igwe-Starking/eccles-bluechat-e2ee/issues/new/choose) with both phones' models and Android versions.
- **Question about using the app?** The in-app Help screen covers connecting, voice notes, calls and blocking. If it does not answer your question, open an issue.
- **Security problem?** Report it privately. See [SECURITY.md](SECURITY.md).
- **Want to help fund the project?** See [the support page](docs/SUPPORT_THE_PROJECT.md).
